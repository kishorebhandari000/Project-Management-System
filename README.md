
  # Homepage for PMS System

  This is a code bundle for Homepage for PMS System. The original project is available at https://www.figma.com/design/lM1np7orMOACJVcybJoc3S/Homepage-for-PMS-System.

  ## Running the code

  Run `pnpm i` to install the dependencies.

-- RUNNING IN 2 TERMINALS  --
  
Run `pnpm run dev` to start the development server.
Right click on `Backend_PMS` folder and select Open In Integrated Terminal then run `pnpm run dev`
